# Tasks

Conventions for every group:

- Group N is milestone M(N-1); the milestone label is in each heading. Groups are strictly sequential.
- Tests and documentation land inside the group that owns the behavior; nothing is deferred to a final group.
- Gate for every group, run locally before the stop: `go build ./... && go vet ./... && go test -race -count=1 ./... && golangci-lint run` (Windows runs the tests without `-race`), plus green CI on Linux, macOS and Windows once M0 is merged.
- All tests are offline: `httptest` fakes, the fake keychain and the fake terminal from `internal/testkit`, temp directories and temp git repositories, injected clock and time zone. Spec scenarios are the test list; the sub-bullets below name the cases that must exist.
- `cli.Deps` grows with each milestone (environment, streams, terminal, clock, location, GOOS/GOARCH, hostname, home directory, keychain, HTTP transport, scrypt work factor); it is the only seam, no globals.
- User-facing text goes into `internal/text/strings.toml` only; Go code passes keys and data.
- Go 1.27.4 is already installed locally (`go version go1.27.4 darwin/arm64`), so M0 starts immediately. Tools used by the gates: `golangci-lint` v2.15.0, `goreleaser` v2.20.2 (only if M11 picks it), `actionlint`.
- The last task of every group is a STOP. It is completed only after the owner reviewed the milestone and said to continue; the next group must not start before that.
